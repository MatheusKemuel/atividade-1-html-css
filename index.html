.O que significa HTML

HTML é a linguagem que cria a estrutura de uma página na web, organizando e definindo todos os elementos que serão exibidos ao usuário.

.O que é TAGS em HTML

As tags HTML são os elementos usados para marcar e organizar o conteúdo de uma página. Elas informam ao navegador qual é a função de cada parte do documento, como um título, um parágrafo, uma imagem ou um link.

.Como define uma TAG no HTML

Uma tag HTML é definida por um nome escrito entre os símbolos de menor < e maior >. Na maioria dos casos, ela possui uma abertura e um fechamento, envolvendo o conteúdo que será exibido. 


                            <nome-da-tag>Conteúdo</nome-da-tag>

.O que são atributos em HTML

Os atributos HTML são informações adicionais adicionadas às tags para definir características ou comportamentos de um elemento.

                        <nome-da-tag atributo="valor">Conteúdo</nome-da-tag>

.Qual a estrutura básica em HTML

Todo documento HTML segue uma estrutura padrão que informa ao navegador como a página está organizada. Ela é composta pelos elementos principais: <!DOCTYPE html>, <html>, <head> e <body>.

.Mais algumas tags HTML

<html>

É a tag raiz de um documento HTML. Todo o conteúdo da página deve estar dentro dela.

<head>

Contém informações sobre a página que não são exibidas diretamente ao usuário, como o título da aba, metadados, links para arquivos CSS e scripts.

<meta>

Define metadados da página, como codificação de caracteres, descrição, autor e configurações para dispositivos móveis.

<title>

Define o título da página, exibido na aba do navegador e utilizado pelos mecanismos de busca.

<body>

Contém todo o conteúdo visível da página, como textos, imagens, links, botões, formulários e listas.

<h1>

Representa o título principal da página. É o cabeçalho de maior importância entre as tags de título, que vão de <h1> até <h6>.

<ol>

Cria uma lista ordenada, exibindo seus itens em ordem numérica ou alfabética.

<li>

Representa um item de uma lista. Deve ser utilizada dentro de uma lista ordenada (<ol>) ou não ordenada (<ul>).

O que significa CSS?

CSS é a sigla para Cascading Style Sheets, que em português significa Folhas de Estilo em Cascata. Ele é a linguagem responsável por definir a aparência e o estilo de uma página HTML, permitindo controlar cores, fontes, tamanhos, espaçamentos, posicionamentos, animações e o layout dos elementos.

.O que é SELETOR em CSS

Um seletor CSS é a parte do código responsável por identificar quais elementos HTML receberão determinado estilo. Ele informa ao navegador quais elementos devem ser modificados pelas regras de estilo definidas.

.Como define quais são os SELETORES no CSS

Os seletores CSS são definidos de acordo com os elementos HTML que você deseja estilizar. Eles podem ser criados utilizando o nome da tag, uma classe, um identificador (id) ou outros padrões de seleção.


                        seletor {
                            propriedade: valor;
                        }

.Qual a estrutura básica em CSS

A estrutura básica do CSS é formada por um seletor e um conjunto de declarações de estilo. Essas declarações definem quais propriedades serão alteradas e quais valores serão aplicados aos elementos HTML.

Estrutura Básica:

                        seletor {
                            propriedade: valor;
                        }

Exemplo:

                            h1 {
                                color: blue;
                                font-size: 32px;
                            }

.Qual a hierarquia de prioridade nos seletores em CSS

No CSS, quando existem várias regras aplicadas ao mesmo elemento, o navegador utiliza uma ordem de prioridade para decidir qual estilo será aplicado. Essa prioridade é chamada de especificidade CSS.
A prioridade dos seletores CSS segue a ordem: Inline → ID → Classe/Atributo/Pseudo-classe → Tag → Universal. Quanto mais específico for o seletor, maior será sua prioridade.

.Mais algumas tags CSS

width

Define a largura de um elemento HTML. Permite controlar o espaço horizontal que o elemento irá ocupar na página.

height

Define a altura de um elemento HTML. Controla o espaço vertical que o elemento irá ocupar.

font-size

Define o tamanho da fonte dos textos. Pode ser utilizado com diferentes unidades de medida, como pixels (px), em, rem ou porcentagem.

text-decoration

Define decorações aplicadas aos textos, como sublinhado, linha sobre o texto ou remoção de decoração.

Exemplos: underline (sublinhado), line-through (riscado) e none (sem decoração).

text-transform

Controla a transformação das letras de um texto, permitindo alterar para maiúsculas, minúsculas ou deixar a primeira letra de cada palavra em maiúscula.

Exemplos: uppercase, lowercase e capitalize.

color

Define a cor do texto de um elemento. Pode receber valores em nomes de cores, hexadecimal, RGB, entre outros formatos.

border

Define uma borda ao redor de um elemento, permitindo configurar sua espessura, estilo e cor.

Exemplo: border: 1px solid black;

margin

Define o espaçamento externo de um elemento, ou seja, a distância entre ele e outros elementos ao seu redor.

padding

Define o espaçamento interno de um elemento, ou seja, a distância entre o conteúdo e a borda do próprio elemento.
